Native Gutenberg code editor block with authorial syntax highlighting, customizable themes, line numbers, and one-click copy.

== Description ==

Luiz0067 Code is a native WordPress Gutenberg block designed for developers, educators, and technical writers who need a high-performance, lightweight code editor inside the block editor.

Built with an authorial, zero-dependency text decoration and syntax highlighting engine, this block offers real-time syntax highlighting, multiple programming languages, instant theme switching, a modern macOS-inspired terminal header with window controls, and a quick copy-to-clipboard button.

The plugin is 100% self-contained and operates completely offline. All JavaScript and CSS assets are bundled locally. Zero external CDNs, third-party libraries, or remote font APIs are loaded.

== Features ==

* **Native Gutenberg Integration (API v3)**: Built with official WordPress block components.
* **Authorial & Zero-Dependency**: 100% custom lightweight syntax decoration engine. No heavy external frameworks.
* **100% Offline**: Operates completely offline with zero external network calls.
* **Multi-Language Support**:
  * JavaScript (ECMAScript, JSX)
  * Python
  * PHP
  * HTML / XML
  * CSS
  * SQL
  * Markdown
* **Real-Time Theme Switcher**:
  * Default (Clean Light)
  * One Dark
  * Dracula
  * Solarized Dark
  * Nord (Arctic Frost)
* **Tab Key Indentation**: Native indentation with Tab inside the editor.
* **Line Numbers & Stats**: Built-in line numbering and live character/line count.
* **Frontend Accessibility**: Accessible, semantic HTML5 output with window controls and a copy-to-clipboard button.
* **Internationalization Ready**: Full i18n support.

== Installation ==

1. Upload the `luiz0067-code` folder to your `/wp-content/plugins/` directory, or install the ZIP file via **Plugins > Add New Plugin > Upload Plugin**.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Open any post or page in the Gutenberg block editor.
4. Insert the block by typing `/code` or searching for **Luiz0067 Code**.

== Frequently Asked Questions ==

= Does this plugin require an internet connection or external CDNs? =
No. The plugin is 100% self-contained and operates completely offline. No CDNs, tracking scripts, or external font APIs are loaded.

= Does this plugin use external third-party libraries? =
No. The syntax highlighting and text decoration engine is an authorial, lightweight implementation with zero third-party dependencies.

= What programming languages are supported? =
JavaScript (ECMAScript, JSX), Python, PHP, HTML/XML, CSS, SQL, and Markdown.

= Can visitors copy the code with one click? =
Yes, the frontend presentation includes an accessible one-click copy button.
